# admin.bergverket.no

Tomt skall for Bergverkets interne dashbord. **Ingen data ligger her.** Siden henter `dashbord.svg` fra det private repoet `bergverket/bergverket-hq` (branch `dashbord`) med hver persons egen GitHub-lesenøkkel, som bare lagres i nettleseren.

Slik lager du nøkkel og hvordan dashbordet tegnes: se `docs/dashbord.md` i bergverket-hq.

Publiseres med GitHub Pages fra `main`. DNS: `admin` CNAME → `bergverket.github.io` (Domeneshop).
